# Sterling Intelligence Briefing

Automated GBP/JPY H4 analysis and reporting system.

## Overview

The Sterling Intelligence Briefing provides regular analysis of the GBP/JPY currency pair, including:
- Current rate and technical levels
- H4 timeframe trend analysis
- Fundamental drivers (BoE, BoJ, political factors)
- Market sentiment analysis
- Outlook and trading scenarios

## Components

### 1. Strategy Configuration

**File**: `config/STERLING_STRATEGY.md`

Defines the analytical framework:
- Technical analysis criteria (moving averages, support/resistance, momentum)
- Fundamental factors to monitor (central bank policy, economic data)
- H4 timeframe structure and reporting format
- Risk factors and key events

### 2. Briefing Generation

Briefings are generated by running a job that:
1. Searches current GBP/JPY rates and price action
2. Gathers recent news and analysis (BoE, BoJ, UK politics)
3. Analyzes market sentiment
4. Summarizes H4 outlook based on the strategy framework
5. Saves briefing to `logs/<JOB_ID>/sterling_briefing_<timestamp>.md`

### 3. Telegram Delivery

**Script**: `event_handler/send-sterling-briefing.js`

Sends the briefing to Telegram with HTML formatting.

#### Manual Usage

From the event handler directory with credentials:

```bash
cd event_handler
TELEGRAM_BOT_TOKEN="<token>" TELEGRAM_CHAT_ID="<chat_id>" \
  node send-sterling-briefing.js [path-to-briefing.md]
```

If no path provided, finds and sends the most recent briefing.

#### Automated via Cron

Add to `operating_system/CRONS.json`:

```json
{
  "name": "send-sterling-briefing",
  "schedule": "0 */4 * * *",
  "type": "command",
  "command": "cd event_handler && node send-sterling-briefing.js",
  "enabled": false
}
```

Enable by setting `"enabled": true` after the first manual briefing is generated.

## Scheduled Briefing Generation

To generate briefings automatically, add to `operating_system/CRONS.json`:

```json
{
  "name": "sterling-briefing",
  "schedule": "0 8,12,16,20 * * *",
  "type": "agent",
  "job": "Generate the 'Sterling Intelligence Briefing'. 1. Check GBP/JPY rates and news. 2. Analyze sentiment. 3. Summarize H4 outlook based on config/STERLING_STRATEGY.md. 4. Post summary to Telegram.",
  "enabled": true
}
```

This generates briefings at 08:00, 12:00, 16:00, and 20:00 UTC (major forex session times).

## Briefing Format

Each briefing includes:
1. **Current Market Status** - Rate, range, bias
2. **Technical Picture** - H4 trend, key levels, momentum
3. **Fundamental Drivers** - GBP and JPY factors
4. **H4 Outlook** - Directional bias, bull/bear scenarios
5. **Risk Factors** - Upcoming events, intervention risk
6. **Summary** - Concise trading strategy

## Customization

### Modify Analysis Framework

Edit `config/STERLING_STRATEGY.md` to adjust:
- Technical indicators
- Fundamental factors
- Outlook structure
- Risk management criteria

### Change Schedule

Modify the cron schedule in `CRONS.json`:
- `*/30 * * * *` - Every 30 minutes
- `0 * * * *` - Hourly
- `0 8,16 * * *` - Twice daily (08:00, 16:00)
- `0 8 * * 1-5` - Daily at 08:00 UTC (weekdays only)

### Additional Currency Pairs

Create similar briefing systems for other pairs:
1. Create `config/<PAIR>_STRATEGY.md`
2. Add cron job with pair-specific prompt
3. Create separate sending scripts if needed

## Dependencies

- **Brave Search API** - For gathering market data and news (requires `BRAVE_API_KEY`)
- **Telegram Bot** - For delivery (requires `TELEGRAM_BOT_TOKEN` and `TELEGRAM_CHAT_ID`)
- **Node.js packages** - `grammy`, `@grammyjs/parse-mode` (for Telegram)

## Notes

- Briefings are saved to logs and committed to the repository
- Historical briefings provide a record of analysis over time
- The system can be extended to include additional data sources (APIs, RSS feeds, etc.)
- Consider rate limits when setting frequent schedules (especially with search APIs)
