## Automation

To automate daily briefings, add this to `operating_system/CRONS.json`:

```json
{
  "name": "sterling-briefing",
  "schedule": "0 16 * * *",
  "type": "agent",
  "job": "Generate the Sterling Intelligence Briefing following config/STERLING_STRATEGY.md. Post to Telegram.",
  "enabled": true
}
```

## Telegram Setup

To enable automatic posting to Telegram:
1. See `../tmp/setup_telegram.md` for detailed instructions
2. Configure `TELEGRAM_BOT_TOKEN` and `TELEGRAM_CHAT_ID` in LLM_SECRETS
3. Run `node ../tmp/send_briefing.js` to test

## Strategy

The briefing strategy is defined in `config/STERLING_STRATEGY.md` and covers:
- Market snapshot (current rates, 24h changes)
- Fundamental drivers (BoJ, BoE, economic data)
- Technical analysis (H4 timeframe focus)
- Sentiment analysis (risk-on/off, positioning)
- H4 outlook with specific levels
- Risk factors (prioritized)
