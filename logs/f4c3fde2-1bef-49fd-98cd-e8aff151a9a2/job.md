Run the weekly CRM sync to update contact profiles from the last 7 days of Gmail and Google Calendar activity.

1. Use `gmcli` to search Gmail for emails from the last 7 days: find new contacts (people who emailed you for the first time) and interactions with existing contacts.
2. Use `gccli` to list calendar events from the last 7 days and extract attendee information.
3. For each person found:
   a. Check if `vault/contacts/<FirstLast>.md` already exists.
   b. If not: create a new contact file with YAML frontmatter (name, email, company if known, role if known, last_contact, tags based on context).
   c. If yes: update `last_contact` date and append a new entry to the `## Interaction Log` section.
4. Regenerate `config/CONTACTS_SUMMARY.md` as a compact markdown table:
   - Columns: Name | Email | Company | Last Contact | Follow-up
   - One row per contact, sorted by last_contact descending
   - Mark follow-up column with the date if `follow_up` frontmatter is set and the date is upcoming
   - Keep the file header: `# Contacts Summary\n<!-- Auto-generated by weekly-crm-sync. Do not edit manually. -->`
5. Send Telegram notification: "✅ CRM sync complete — [N] contacts updated, [M] new contacts added."

Contact file format:
```yaml
---
name: Full Name
email: email@example.com
phone: (optional)
company: (optional)
role: (optional)
last_contact: YYYY-MM-DD
follow_up: YYYY-MM-DD (optional)
tags: [client, investor, etc.]
---
## Interaction Log
### YYYY-MM-DD — Email
Summary of the interaction...
```
